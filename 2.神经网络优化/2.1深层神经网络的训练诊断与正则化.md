# 一、训练集、验证集、测试集

## 1. 作用

- `训练集（Train set）`：用于学习参数
- `验证集（Dev set / Validation set）`：用于过程中模型选择与超参数调节
- `测试集（Test set）`：用于对最终模型做无偏评估

## 2. 比例划分

1. 传统
	- 60% train + 20% dev + 20% test
2. 大数据
	
- 训练集尽量大
- 验证集和测试集只要足够评估即可（如1万左右）

## 3.分布一致性

- **验证集和测试集必须来自同一分布**

> 如果验证集和测试集不一致，那么你在验证集上选出来的“最优模型”，很可能在测试集上并不最优。

# 二、偏差与方差

## 1. 基本概念

- **高偏差（high bias）**：模型太简单，训练集误差大，也叫欠拟合
- **高方差（high variance）**：模型过复杂，测试集正确率距训练集误差大，泛化不好，也叫过拟合

| Train Error | Dev Error | 现象分析 | 结论 |
|---|---|---|---|
| 1% | 11% | 训练集学得很好，但验证集误差明显升高 | 高方差（Overfitting） |
| 15% | 16% | 连训练集都没学好，Dev 仅略差于 Train | 高偏差（Underfitting） |
| 15% | 30% | 训练集学不好，且 Dev 明显进一步恶化 | 高偏差 + 高方差 |
| 0.5% | 1% | 训练集与验证集都表现优秀 | 偏差和方差都低 |

## 2. 解决方案

1. 高方差
	
	- 使用更大的网络
	- 增加隐藏层数量
	- 增加每层隐藏单元数量
	- 训练更久
	- 尝试更好的优化算法
	- 更换更合适的网络结构
	
2. 如果是高方差，怎么处理
	
	- 获取更多训练数据
	- 使用正则化
	- 采用 dropout
	- 进行数据扩增
	- 使用 early stopping
	- 必要时重新设计模型结构

# 三、正则化

##  1、L2正则化

1. 概念

$J(w,b)=\frac{1}{m}\sum_{i=1}^m L(\hat y^{(i)}, y^{(i)})+\frac{\lambda}{2m}\|w\|_2^2$

其中：

$\|w\|_2^2=\sum_{j=1}^{n_x}w_j^2 = w^T w$

- 新增的正则项希望权重不要太
- b与过拟合无关，只约束w


2. L1 正则化与 L2 正则化的区别

L1 正则化形式：

$\frac{\lambda}{m}\sum_{j=1}^{n_x}|w_j|$

- 得到的参数向量更稀疏
- 很多分量会被压成 0

但在深度学习实践中，更常用的还是 L2 正则化。因为：

- 它更稳定
- 更符合大多数神经网络训练习惯


3. 原理

$dW^{[l]}=dW^{[l]}_{\text{原始}}+\frac{\lambda}{m}W^{[l]}$

$W^{[l]}:=W^{[l]}-\alpha dW^{[l]}_{\text{原始}}-\alpha \frac{\lambda}{m}W^{[l]}$

把关于 $W^{[l]}$ 的项整理一下，会看到它相当于：

$W^{[l]} \leftarrow \left(1-\alpha\frac{\lambda}{m}\right)W^{[l]} - \alpha dW^{[l]}_{\text{原始}}$

- $1-\alpha\frac{\lambda}{m} < 1$

权重会被持续缩小，故L2 正则化也常被叫做`权重衰减（weight decay）`。


---

## 2.为什么正则化可以降低过拟合


1. 让模型变简单

如果正则化系数 $\lambda$ 很大，那么最优解会倾向于让各层权重 $W^{[l]}$ 变小。

- 但它们对输出的影响被削弱了
- 整个网络有效复杂度下降

于是一个原本非常容易过拟合的复杂网络，会被拉回到更简单的状态。


2. 让非线性激活更接近线性区间

以 `tanh` 为例，当输入 $z$ 很小时，$tanh(z)$ 在原点附近近似线性

- $W$ 变小 ， $z=Wx+b$ 也变小
- 激活函数更容易停留在线性区间附近

那么整个深层网络的整体表达也会更接近一个较简单的线性映射，复杂程度降低。

3. 记得用新代价函数

如果你给模型加入了正则化，然后想观察梯度下降过程中代价函数是否单调下降，那么必须用新的代价函数：

- 原损失项
- 加上正则

## 3.Dropout 正则化

### 1. 基本思想

它的核心目的，是让网络不要过度依赖某几个局部通路或局部特征。

- 每次训练时都在训练一个子网络（残缺）
- 最终相当于很多子网络的集成效果


### 2. Inverted Dropout 的实现过程

```python
d3 = np.random.rand(a3.shape[0], a3.shape[1])
d3 = d3 < keep_prob
a3 = np.multiply(a3, d3)
a3 = a3 / keep_prob
```

可以分成四步理解：

1. 生成与激活矩阵同形状的随机掩码
2. 以 `keep_prob` 的保留概率保留一部分单元
3. 没保留的单元激活值直接清零
4. 为了**保持期望不变**，再除以 `keep_prob`（让下一层收到的范围不变）


Dropout 原理：分散权重w
	
- 一个神经元不能指望自己永远依赖固定的几个输入（可能会被删除）
因此它会倾向于：
- 而是把信息更分散地编码到多个路径中，让权重产生“缩小”的趋势	
- 所以它在效果上类似一种自适应的正则化


### 3. 不同层的 keep_prob 可以不同

- 参数特别多、容易过拟合的层，可以把 `keep_prob` 设得小一些
- 不太容易过拟合的层，可以把 `keep_prob` 设得大一些
- 某些层如果不想做 dropout，就设 `keep_prob = 1`

对于输入层：dropout一般很小

### 4. Dropout 的缺点与调试方法

- 所以严格来说，优化的代价函数并不是一个固定的、容易直接观察的 $J$

- 很难再像普通梯度下降那样，用“$J$ 是否单调下降”来排查 bug

**故一般关闭再打开进行实验**

## 5.其他正则化方法

### 1. 数据扩增

数据扩增本质上是在不额外采集新数据的情况下，构造更多增强的训练样本

- 如 水平翻转 随机裁剪 适度缩放 轻微旋转

它的作用是：

- 扩大训练集规模，降低过拟合
- 提高模型对输入扰动的鲁棒性

需要注意的是：

- 变换必须符合任务语义
- 比如猫左右翻转还是猫，但上下颠倒未必合理

### 2. Early Stopping

它利用的现象通常是：

- 训练误差随着迭代持续下降
- 验证误差先下降，后上升（过拟合）

因此在验证误差最优点停止训练，就能在一定程度上抑制过拟合。

- 本质与缺点
	
	- 让参数还没长到特别大时就停下来，从而限制w规模
	
	但它把两个本来应该独立处理的问题混在了一起：
	
	- 一个问题是：怎样把训练目标 $J$ 优化得更小
	- 另一个问题是：怎样防止过拟合
	
	如果使用 early stopping，第一个要求还没有得到满足，就因为第二个停下来

# 四、输入归一化

## 1. 原理

- 让优化过程更稳定
- 让梯度下降更快收敛
- 优化函数 船->碗，梯度下降更均匀不会震荡且学习率更大
![[Pasted image 20260529161436.png|394]]

## 2. 归一化的两步
1. 均值归一
	- $\mu = \frac{1}{m}\sum_{i=1}^{m}x^{(i)}$
		
	- $x  -= \mu$

2. 方差归一

- 按特征维度计算方差或标准差尺度
- 再对每个特征做缩放

目标是让不同特征处于相似量级。

## 3. 工程规则

验证集和测试集，都必须使用`训练集统计出来的均值和方差`去做归一化，保证变换相同

# 五、梯度消失与梯度爆炸

## 1. 问题本质

对于深层网络，激活值和梯度要经过多层连乘。

- 如果每层都略大于 1，那么多层相乘后会指数增长，形成`梯度爆炸`
- 如果每层都略小于 1，那么多层相乘后会指数衰减，形成`梯度消失`

会影响前向和反向传播中激活的量级， 从而导致学习过慢或震荡

## 2. ReLU 常用初始化

课程给出的 ReLU 常用初始化形式是：

$W^{[l]} = \text{np.random.randn(shape)} \cdot \sqrt{\frac{2}{n^{[l-1]}}}$

- $n^{[l-1]}$ 是上一层单元数
- $\sqrt{2/n^{[l-1]}}$ 的作用是控制权重方差

## 3. tanh 常用初始化

如果激活函数是 `tanh`

$W^{[l]} = \text{np.random.randn(shape)} \cdot \sqrt{\frac{1}{n^{[l-1]}}}$

## 4. 原理

- 让每层输出方差不要因为层数增加而迅速放大或缩小
- 从而减缓梯度消失和梯度爆炸

# 六、梯度检验

## 1. 导数的双边差分公式

$g(\theta)\approx \frac{f(\theta+\varepsilon)-f(\theta-\varepsilon)}{2\varepsilon}$

- 为什么双边差分比单边差分更好
	
	- 双边误差是：$O(\varepsilon^2)$
	
	- 单边误差是：$O(\varepsilon)$

## 2. 目的

- 验证反向传播中梯度计算是否正确

## 3. 基本思路

1. 把$W^{[1]}, b^{[1]}, \dots, W^{[L]}, b^{[L]}$全部展平并拼接成一个大向量：$\theta$
	
	把反向传播得到所有梯度$dW^{[1]}, db^{[1]}, \dots, dW^{[L]}, db^{[L]}$也拼接成一个大向量：$d\theta$
	
	- 转化为检查向量 $d\theta$ 是否接近数值近似得到的 $d\theta_{approx}$
	
2. 对每个参数做数值梯度近似
	
	对于第 $i$ 个参数分量 $\theta_i$，构造：
	
	$$d\theta_{approx}[i]=
\frac{J(\theta_1,\dots,\theta_i+\varepsilon,\dots)-J(\theta_1,\dots,\theta_i-\varepsilon,\dots)}{2\varepsilon} $$
	
	- 把第 $i$ 个分量作为自变量
	
	最终得到：$d\theta_{approx}$

3. 如何判断是否接近
	
	$\frac{\|d\theta_{approx}-d\theta\|_2}{\|d\theta_{approx}\|_2+\|d\theta\|_2}$ 越小越接近
- 经验上：
	
	- 如果结果在 $10^{-7}$ 量级或更小，通常说明实现很好
	- 如果在 $10^{-5}$ 左右，要提高警惕
	- 如果在 $10^{-3}$ 或更大，基本就要怀疑有 bug

## 4. 使用方式

梯度检验计算开销很大 通常只在调试阶段使用

1. 小规模网络上先做梯度检验（关闭dropout）
2. 确认 backprop 没问题
3. 关闭梯度检验
4. 再进行正式训练

# 七、本周主线回收

## 1. 这周真正建立起来的思维框架

这一周最核心的收获，不是记住某一个技巧，而是建立起一整套工程化训练思路：

- 先把数据集划分好，保证评估机制可信

- 如果是高方差，就通过正则化、数据扩增等手段降低过拟合

# 八、复习抓手

## 1. 必会判断题

- train error 高、dev error 也高且接近：高偏差
- train error 低、dev error 高很多：高方差
- dev/test 最重要的要求：同分布
- dropout 测试阶段：不用 dropout
- 归一化时 dev/test 的均值方差：必须用训练集统计量
- 梯度检验使用：双边差分，不是单边差分

## 2. 必会公式

- L2 正则化：

$J=\frac{1}{m}\sum_i L(\hat y^{(i)}, y^{(i)})+\frac{\lambda}{2m}\sum_l \|W^{[l]}\|_F^2$

- 正则化梯度：

$dW^{[l]}=dW^{[l]}_{\text{原始}}+\frac{\lambda}{m}W^{[l]}$

- 双边差分：

$\frac{f(\theta+\varepsilon)-f(\theta-\varepsilon)}{2\varepsilon}$

- ReLU 初始化：

$W^{[l]} \sim \sqrt{\frac{2}{n^{[l-1]}}}$

- tanh 初始化：

$W^{[l]} \sim \sqrt{\frac{1}{n^{[l-1]}}}$

## 3. 必会工程意识

- 不要一上来盲调超参数，先诊断偏差还是方差
- 正则化后调试代价函数时，要用新的正则化代价函数
- dropout 先关掉调通，再打开
- 梯度检验只在调试时开，正式训练时关
