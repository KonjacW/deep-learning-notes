# 二、经典网络：LeNet-5

## 1. 结构与输入
![[Pasted image 20260602220730.png]]

- 输入是灰度图，典型尺寸为 $32 \times 32 \times 1$。
- 结构主线是：
1. Conv -> Pool
2. Conv -> Pool
3. FC -> FC -> Output

## 2. 早期网络特点
- 常用 **average pooling**
- 常用 **sigmoid / tanh**
- 基本不用今天常见的 ReLU
- 通常不用 `padding`，所以高宽会持续缩小

## 3. 尺寸变化规律与参数规模
- 尺寸变化体现出一个经典规律：
1. 空间尺寸越来越小
2. 通道数越来越大
- 参数量不大，约 $6 \times 10^4$。

## 4. LeNet 奠定的经典模式
1. 若干卷积层
2. 接池化
3. 再若干卷积层
4. 再接池化
5. 最后全连接输出

# 四、经典网络：AlexNet

## 1. 基本结构与规模
![[Pasted image 20260602220750.png]]

- 输入典型为 $227 \times 227 \times 3$。
- 典型结构是多层卷积后接全连接，再接 softmax 输出 1000 类。

## 2. 相比 LeNet 的变化
1. 网络更大
2. 参数更多，约 6000 万
3. 使用 **ReLU**
4. 使用 **max pooling**

## 3. 历史意义
1. 让 CV 社区真正重视深度学习
2. 推动深度学习在视觉中的爆发

## 4. 论文中的一些细节
1. 当时为了算力限制，做了双 GPU 训练拆分
2. 用过 **LRN（Local Response Normalization）**

## 5. 今天更值得记住的点
1. 更深更大网络可行
2. ReLU 很关键
3. 大数据集 + GPU + 深网络开始形成标准范式

# 五、经典网络：VGG-16

## 1. 核心设计思想
![[Pasted image 20260602220826.png]]

- 全部用 $3 \times 3$、stride=1、same padding 的卷积
- 用 $2 \times 2$、stride=2 的池化降采样

## 2. 结构规律
1. 每次池化后，高宽减半
2. 通道数按组翻倍：64 -> 128 -> 256 -> 512

## 3. 优点
1. 结构简单
2. 规则统一
3. 容易理解与复用

## 4. 缺点
- 参数量极大，约 1.38 亿

## 5. VGG 的意义
- VGG 的意义不只是效果，而是展示了一种“规则化堆叠深网络”的设计哲学。

# 六、残差网络 ResNet（Residual Networks）

## 1. 普通两层块与残差块
- 普通两层块：
$$
z^{[l+1]} = W^{[l+1]} a^{[l]} + b^{[l+1]}, \quad a^{[l+1]} = g(z^{[l+1]})
$$
$$
z^{[l+2]} = W^{[l+2]} a^{[l+1]} + b^{[l+2]}, \quad a^{[l+2]} = g(z^{[l+2]})
$$
- 残差块加入跳跃连接后变成：
$$
a^{[l+2]} = g\left(z^{[l+2]} + a^{[l]}\right)
$$
![[Pasted image 20260603090136.png]]
## 2. Skip Connection 的作用
1. 把较浅层激活直接送到更深层
2. 加法发生在线性变换后、ReLU 前
3. 这样形成 **Residual block**

## 3. 为什么深网络难训练
- 普通深网络随着层数增加，理论上表达能力更强。
- 但训练时常出现：
1. 梯度消失
2. 梯度爆炸
3. 优化困难
- 实际表现是：深度继续加大后，训练误差反而上升。

## 4. 为什么 ResNet 有效
- 残差块很容易学习恒等映射（identity mapping）。
- 如果新增两层学不到有用东西，也至少可以学成：
$$
a^{[l+2]} = g\left(z^{[l+2]} +  a^{[l]}\right)
$$
$$
a^{[l+2]} \approx a^{[l]}
$$
- 这意味着：
	1. 加深网络不会轻易把性能做坏
	2. 最差接近“原网络”
	3. 更好时还能学到额外增益
- 所以 ResNet 的关键不是“每层都一定更强”，而是“更深网络至少不容易退化”。

## 5. 维度匹配
- 最简单的残差连接要求输入输出维度一致，所以常配合 **same convolution**。
- 若维度不一致，可引入投影矩阵 $W_s$：
$$
a^{[l+2]} = g\left(z^{[l+2]} + W_s a^{[l]}\right)
$$
- 一般的结构是conv-conv-....-pool-

# 七、1×1 卷积（Network in Network）

## 1. 它本质上在做什么
- 对单通道输入，1×1 卷积看起来只是乘一个数。
- 对多通道输入，1×1 卷积本质上是在每个空间位置上，对通道维做一次小型全连接计算，再接非线性。

## 2. 它的作用
1. 做跨通道特征组合
2. 加入非线性
3. 压缩/保持/增加通道数

## 3. 典型用途
- 把 $28 \times 28 \times 192$ 压到 $28 \times 28 \times 32$。

# 八、Inception 的动机与结构

## 1. Inception 的核心思路
	
-  不替网络提前做唯一选择
-  而是把多种分支都做出来
-  最后把结果拼接，**让网络自己学**

## 3. 基本 Inception 模块
- 对同一输入并行做：
	1. 1×1 conv
	2. 3×3 conv
	3. 5×5 conv
	4. pooling
- 各分支保持相同高宽后，在通道维上拼接（concatenate）。
![[Pasted image 20260603093243.png]]
## 4. 瓶颈层
- 直接做 5×5 卷积很贵。
- 解决办法：先用 1×1 conv 降通道，再做 3×3 或 5×5。
- 作用：
	1. 明显减少计算量
	2. 通常不明显损伤性能

## 5. 完整 Inception 网络
1. 整体就是很多 Inception 模块堆叠
2. 中间穿插池化改变高宽
3. 论文中还用了辅助分类分支
	- 帮助中间层学习
	- 起一定正则化作用

# 九、轻量化网络：MobileNet

## 1. 特点
1. 参数少
2. 计算量低
3. 推理快
4. 能在手机、嵌入式设备、边缘设备上运行
- MobileNet 就是在这种背景下提出的轻量化 CNN。

## 2. 核心思想
- 标准卷积计算代价高，因为它同时在做：
	1. 空间维上的卷积
	2. 通道维上的混合
- MobileNet 的核心做法是把这两件事拆开：
	1. **Depthwise Convolution**
	2. **Pointwise Convolution（1×1 Conv）**
- 这种结构叫 **Depthwise Separable Convolution**。

## 3. 这样做为什么更省计算

- 标准卷积计算量大致与下面成正比：

![[Pasted image 20260603131623.png]]

$$
D_k^2 \cdot M \cdot N \cdot D_f^2
$$
- 其中：
- $D_k$：卷积核尺寸
- $M$：输入通道数
- $N$：输出通道数
- $D_f$：特征图空间尺寸


![[Pasted image 20260603131549.png|330]]
![[Pasted image 20260603131458.png|336]]
- Depthwise Separable Convolution 的计算量大致变成：
$$
D_k^2 \cdot M \cdot D_f^2 + M \cdot N \cdot D_f^2
$$

- 因此相比标准卷积，计算量显著下降。
- 当卷积核是 $3 \times 3$ 时，常见结论是：在相近表达目标下，计算和参数都能明显减少。

## 4. MobileNet 的基本结构

![[Pasted image 20260603131207.png|465]]

- 主体结构可以理解为：
	1. 普通卷积起步
	2. 后面大量堆叠 depthwise separable convolution
	3. 最后接分类层
- 其中每个轻量模块通常包含：
	1. depthwise conv
	2. pointwise conv
	3. 非线性激活
	4. 可能再配合 BatchNorm

## 5. MobileNet 的两个重要超参数
- 为了进一步控制模型大小和速度，MobileNet 引入了两个常见系数：

1. **Width Multiplier**（宽度系数）
	- 记作 $\alpha$
	- 用来按比例缩小每层通道数
		
	- $\alpha$ 越小：
		- 参数更少
		- 计算更低
		- 精度通常也会下降

2. **Resolution Multiplier**（分辨率系数）
	- 用来缩小输入图像或中间特征图分辨率
		
	- 分辨率越低：
		- 计算更低
		- 推理更快
		- 但细节信息也更容易损失

## 7. MobileNet 的优点
	
1. 参数量小
2. 计算量低
3. 推理速度快
4. 很适合移动端和边缘端部署

## 8. MobileNet 的代价与局限
1. 轻量化通常会带来一定精度损失
2. 在**算力充足**场景下，未必比大模型更优
3. 过度压缩后，表达能力会明显下降

## 9. MobileNet 的意义
- 它的重要性不只是“模型变小了”，而是明确展示了一条 CNN 设计路线：
1. 不只追求更深更大
2. 还可以追求更便宜、更快、更适合部署
- 如果说 VGG、ResNet、Inception 更强调“如何提升表示能力”，那 MobileNet 更强调“如何在资源受限条件下保留尽可能多的有效能力”。

# 十、模型缩放：EfficientNet

## 1. 为什么还需要 EfficientNet

- 但另一个很实际的问题是：当我们想把模型做得更强时，应该优先放大什么？
	1. 加深网络（depth）
	2. 加宽网络（width）
	3. 提高输入分辨率（resolution）

- 传统做法往往只放大其中一个维度，但这样通常不够均衡：
	1. 只加深，优化会更难，收益也可能变小
	2. 只加宽，计算量会上升很快
	3. 只提分辨率，前面层未必能充分利用额外细节

- EfficientNet 的核心问题就是：
- 如何用更系统、更均衡的方式放大模型，使参数、计算量和精度之间更划算。

## 2. EfficientNet 的核心思想
- EfficientNet 的核心不是发明一个全新的卷积算子，而是提出了 **compound scaling
- 它的思路是：
	- 不单独放大 depth、width 或 resolution
	- 而是按一组协调比例，同时放大这三个维度
- 这三件事一起做，并且按比例协调。

## 3. 什么是 compound scaling
- EfficientNet 用一个统一缩放系数控制模型大小，记作 $\phi$。
- 然后用三个常数控制三个维度的增长：
	1. depth：$\alpha^\phi$
	2. width：$\beta^\phi$
	3. resolution：$\gamma^\phi$

- 约束关系通常写成：
$$
\alpha \cdot \beta^2 \cdot \gamma^2 \approx 2
$$


## 4. 为什么这种缩放更合理
- 深度增加有助于提升层级特征表达能力。
- 宽度增加有助于提升每层的通道表达能力。
- 分辨率增加有助于保留更细的空间细节。
- 三者本来就是耦合的：
	1. 分辨率提高后，需要足够的深度和宽度去消化信息
	2. 网络更深更宽后，也需要足够分辨率才能发挥效果

## 5. EfficientNet 的基础网络

- 一个效果和效率都不错的模型，通常记作 **EfficientNet-B0**。
- 然后在 B0 的基础上，通过 compound scaling 逐步得到：多个EfficientNet-Bx

## 7. EfficientNet 的优点
1. 在相同或相近计算预算下，通常能取得更好的精度
2. 模型缩放规则更统一，不需要每次手工猜该加深还是加宽
3. 在参数量、FLOPs 和精度之间，往往有更好的平衡
4. 给后续模型设计提供了“系统缩放”这条重要思路

## 8. EfficientNet 的代价与局限
1. 它依然依赖一个好的 baseline 结构
2. compound scaling 不是对所有任务都必然最优
3. 在不同硬件和不同部署环境下，理论 FLOPs 优势不一定完全等于真实延迟优势
4. 分辨率升高后，显存和训练成本仍然会上升

## 9. EfficientNet 的意义
- EfficientNet 的意义不只是“又一个精度更高的模型”，而是提出了一个很重要的方法论：
- 模型变大不应该只靠直觉乱放大
- 应该用统一规则协调 depth、width、resolution

- 如果说：
1. ResNet 解决的是“更深网络怎么训”
2. MobileNet 解决的是“更轻模型怎么做”
3. EfficientNet 解决的就是“模型怎么更合理地放大”

## 10. 和前面内容的关系
1. 和 **ResNet** 的关系：ResNet 证明了深层网络可以稳定训练，EfficientNet 则进一步讨论“深度该如何与其他维度一起扩展”。
2. 和 **MobileNet** 的关系：MobileNet 更偏轻量模块设计，EfficientNet 更偏整体缩放策略。
3. 和 **工程方法** 的关系：EfficientNet 很符合真实工程里的核心问题，即在有限算力和资源下尽量提高精度。
4. 和 **计算机视觉现状** 的关系：它体现了现代 CV 不只追求更大模型，也追求更好的效率-性能权衡。

# 九、使用开源实现

## 1. 为什么很多视觉论文难复现
	
1. 学习率衰减
2. 训练细节
3. 初始化
4. 其他工程超参数

## 2. 实用流程
1. 先选架构
2. 找作者或社区的开源实现
3. 直接复用代码和配置
4. 再在此基础上改

## 3. 这样做的好处
1. 节省复现成本
2. 少踩实现细节坑
3. 更容易继续做迁移学习

# 十、迁移学习（Transfer Learning）

## 1. 基本思想
- 不从随机初始化开始，而是加载别人已在大数据集上训练好的权重。
- 常见预训练来源：
	1. **ImageNet**
	2. **MS COCO**
	3. **Pascal** 等
	
## 2. 小数据集做法
1. 替换最后的 softmax 输出层，使其适配自己的类别数
2. 冻结前面大部分层，只训练最后分类层
3. 这时前面网络相当于固定特征提取器
![[Pasted image 20260603134150.png]]
## 3. 进一步提速技巧
1. 如果前面层完全冻结，可以先把中间特征预计算并存盘
2. 然后只在这些特征上训练最后分类器

## 4. 数据变大后的做法
- 数据越多，冻结层数越少。
- 可以：
1. 只冻结前几层
2. 微调后几层
3. 最后过渡到全网络微调

## 5. 经验规律
1. 数据少：更多冻结，少量训练
2. 数据中等：训练后几层
3. 数据很多：预训练权重做初始化，训练整个网络

# 十一、数据增强（Data Augmentation）

## 1. 为什么重要
- 视觉任务通常“永远嫌数据不够”，所以数据增强很重要。

## 2. 常见方法
1. 镜像翻转（flip）
2. 随机裁剪（random crop）
3. 颜色扰动（RGB distortion）
4. 更复杂的旋转、剪切、局部形变等

## 3. 颜色增强
1. 对 R/G/B 通道加扰动，提高模型对光照、色温变化的鲁棒性
2. 更高级方法包括 **PCA color augmentation**算法

## 4. 工程实现
- 大数据集训练时，常用 CPU 线程/多线程：
	1. 从硬盘加载图片
	2. 在线做随机变换
	3. 组成 mini-batch
	4. 再送入 GPU 训练
- 这样可以把数据处理和模型训练并行化。


# 十二、计算机视觉现状（The State of Computer Vision）

## 1. CV 比很多领域更缺数据

## 2. 数据量与方法风格的关系
- 数据量与结构简单程度成正比，与人工设计量成反比
## 3. CV 为什么经常架构复杂
1. 因为长期以来视觉任务的数据不算“足够多”
2. 所以研究者会投入很多精力做结构设计、技巧拼装、超参数工程

## 4. 两个知识来源
1. 标注数据 $(x, y)$
2. 手工工程（结构设计、技巧、先验）

## 5. 竞赛技巧 vs 生产系统
- 为 benchmark 提升成绩，常见技巧：
1. **ensemble**
2. **multi-crop at test time**
- 它们能涨点，但代价是：
1. 更慢
2. 更耗内存
3. 更不适合真实部署
- 生产更看重：
1. 速度
2. 资源
3. 稳定性
4. 可维护性

## 6. 最终工程建议
1. 优先复用别人已经验证过的架构和预训练权重
2. 先做迁移学习，再考虑从头训练
3. 真要从头训练，前提通常是：
	- 数据极大
	- 算力很足
	- 目标是研究新算法而不是快速落地
