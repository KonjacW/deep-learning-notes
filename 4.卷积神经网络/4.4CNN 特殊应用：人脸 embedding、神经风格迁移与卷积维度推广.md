# 〇、总框架

这周的内容不是新的 CNN 基础层，而是 CNN 的三类代表性特殊应用：

1. **人脸识别（Face Recognition）**
- 从普通分类问题转向 **embedding + similarity**。
- 关键词：**one-shot learning**、**Siamese network**、**Triplet Loss**。

2. **神经风格迁移（Neural Style Transfer, NST）**
- 把图像拆成 **内容（content）** 和 **风格（style）** 两部分分别约束。
- 关键词：**content cost**、**style cost**、**Gram matrix**。

3. **1D / 3D 卷积推广**
- 卷积思想不只适用于 2D 图像。
- 本质仍然是：**局部连接 + 参数共享 + 跨位置复用同一 detector**。

# 一、人脸识别的问题建模

## 1. 人脸验证与人脸识别不是一回事

这两类任务的输入形式相似，但难度层级不同。复习时一定先分清任务定义，否则后面的损失函数和部署逻辑会混掉。

| 任务                      | 输入         | 输出             | 本质       | 难点           |
| ----------------------- | ---------- | -------------- | -------- | ------------ |
| 人脸验证（Face Verification） | 图片 + 身份 ID | 是否是这个人         | $1:1$ 判断 | 只需判断“像不像该身份” |
| 人脸识别（Face Recognition）  | 图片 + 人脸库   | 是库中哪一个人 / 不在库中 | $1:K$ 判断 | 验证器错误会在大库中放大 |

1. **验证更基础**
- 课程先讲 verification，再把它扩展到 recognition。
- 因为只要 verification 足够强，recognition 就能通过“对库中所有人逐个比较”搭起来。

2. **识别更难**
- 假设验证器单次错误率是 $1\%$。
- 如果要在一个较大人脸库上逐个比，整体出错机会会显著增加。
- 所以识别任务要求的底层 verification 精度通常更高。

## 2. one-shot learning 是核心约束

人脸系统的真实难点不是“类别很多”，而是“每个人往往只有极少样本”。

1. **one-shot learning**
- 系统经常只有某个人的一张注册照。
- 但推理时又要认出该人的其他姿态、光照、表情下的图片。

2. **为什么不能直接 softmax 分类**
- 每人只有一张图，训练集太小，分类器不稳。
- 新员工加入后，类别数变化，输出层要改。
- 这会把系统做成“封闭类集分类器”，扩展性很差。

3. **这一约束决定了建模方向**
- 目标不再是“直接预测是谁”。
- 而是学一个“同人应接近、异人应远离”的相似度空间。

## 3. 相似度函数才是真正要学的东西

解决 one-shot 的关键不是多类分类，而是学习一个距离函数。

1. 定义相似度 / 距离函数
$$
d(img_1, img_2)=\text{degree of difference between images}
$$

2. 目标性质
- 若两张图是同一个人，$d$ 应该小。
- 若两张图不是同一个人，$d$ 应该大。

3. 推理规则
- 给定阈值 $\tau$：
- 若 $d(img_1, img_2) \le \tau$，判为同人。
- 若 $d(img_1, img_2) > \tau$，判为异人。

4. 这一建模的真正好处
- 新人加入时，不需要重训整个系统。
- 只要把新人的参考图加入数据库即可。

# 二、Siamese Network 与 embedding 学习

## 1. Siamese 网络在学什么

Siamese 的本质不是“两张图一起分类”，而是“用共享参数网络把两张图映射到同一个 embedding 空间”。

1. 对任意输入图像 $x$，网络输出一个编码：
$$
f(x)
$$

2. 课程中的典型设定
- $f(x)$ 可以是 128 维向量。
- 它表示该图像在语义空间中的身份特征。

3. 两张图的距离常定义为
$$
d\bigl(x^{(1)},x^{(2)}\bigr)=\left\|f(x^{(1)})-f(x^{(2)})\right\|_2^2
$$

4. 这里的关键不是距离公式本身，而是：
- CNN 参数决定了 $f(x)$。
- 训练的本质是把参数调到使 embedding 具有“身份可分性”。

## 2. 好的 embedding 应该满足什么性质

Siamese 网络训练成功与否，不看分类准确率，而看 embedding 空间结构是否对。

1. **同人近**
- 若 $x^{(i)}$ 与 $x^{(j)}$ 是同一个人：
$$
\left\|f(x^{(i)})-f(x^{(j)})\right\|^2
$$
应尽量小。

2. **异人远**
- 若两张图不是同一个人，上式应尽量大。

3. **共享参数是必要条件**
- 上下两支 CNN 不是两个独立网络。
- 它们必须共享参数，否则“距离空间”没有统一意义。

## 3. Siamese 解决 one-shot 的方式

这一结构为什么能解决 one-shot，要从“学习对象”角度理解。

1. softmax 学的是“有限类别决策边界”。
2. Siamese 学的是“图片对之间的相似性规律”。
3. 因此它天然支持：
- 训练时见过的人；
- 推理时新加入的人；
- 只要新人的一张参考图能提供 embedding。

4. **一句话总结**
- softmax 在学“谁是谁”。
- Siamese 在学“像不像同一个人”。

# 三、Triplet Loss 与二分类训练

## 1. Triplet Loss 的目标与 margin

Triplet Loss 是最经典的人脸 embedding 学习方法之一。它直接规定了 embedding 空间应该长什么样。

1. 三元组定义
- **Anchor**：$A$
- **Positive**：$P$，与 $A$ 同人
- **Negative**：$N$，与 $A$ 异人

2. 基本目标
$$
\|f(A)-f(P)\|^2 \le \|f(A)-f(N)\|^2
$$

3. 但这个目标还不够
- 若所有图片都映射到同一个向量，条件也成立。
- 这会出现完全无用的退化解。

4. 所以必须加入 **margin** $a$
$$
\|f(A)-f(P)\|^2 - \|f(A)-f(N)\|^2 + a \le 0
$$

5. 对应的三元组损失函数
$$
L(A,P,N)=\max\left(\|f(A)-f(P)\|^2-\|f(A)-f(N)\|^2+a,\ 0\right)
$$

6. 这里的 $a$ 表示什么
- 不是“负样本只要比正样本远一点”。
- 而是“必须远出至少一个安全间隔”。

## 2. Triplet Loss 为什么有效

Triplet Loss 的价值，不只在公式，更在它对空间几何结构的强约束。

1. 若 loss 为 0
- 说明这个三元组已经满足：
- 正样本足够近；
- 负样本足够远；
- 并且远出了 margin。

2. 若 loss 大于 0
- 说明三元组还不合格。
- 训练会推动：
- $d(A,P)$ 变小；
- 或 $d(A,N)$ 变大；
- 或两者同时发生。

3. 学到的结果
- 同人样本会在 embedding 空间形成紧簇。
- 异人样本簇之间会被拉开。

## 3. Triplet 训练的数据要求与难样本选择

这部分是最容易被忽略的工程条件，但实际非常关键。

| 问题 | 结论 | 原因 |
| --- | --- | --- |
| 训练阶段能否只有每人一张图 | 不能 | 构不出 Anchor-Positive 对 |
| 随机选 triplet 是否足够 | 通常不够 | 太多 triplet 太简单，loss 近 0 |
| 为什么要选 hard / semi-hard triplet | 为了让梯度真正工作 | 只有接近决策边界的样本才推动学习 |

1. **训练集不能真 one-shot**
- 推理可以 one-shot。
- 训练不可以。
- 训练集至少要有一部分人拥有多张照片。

2. **随机 triplet 往往太简单**
- 随机选的负样本通常本来就离得很远。
- 这种样本已经满足约束，几乎不给有效梯度。

3. **难样本更有价值**
- 希望选那些：
$$
d(A,P)\approx d(A,N)
$$
- 也就是“正样本不够近、负样本不够远”的情况。

4. **工程结论**
- Triplet mining 往往直接决定训练效率。
- 好的 mining 比单纯堆更多简单样本更重要。

## 4. 另一条路：把验证当成二分类

Triplet Loss 不是唯一方案，还可以把“是否同人”直接做成 pairwise binary classification。

![[Pasted image 20260605192547.png]]

1. 输入
- 一对图片 $(x^{(i)}, x^{(j)})$。

2. 标签
- $y=1$：同人
- $y=0$：异人

3. 一种常见分类头
$$
\hat y=\sigma\left(\sum_{k=1}^{128} w_k\left|f(x^{(i)})_k-f(x^{(j)})_k\right| + b\right)
$$

4. 含义
- 先算两个 embedding。
- 再把逐维差异作为特征，喂给一个 sigmoid 二分类器。

5. 这一方法的优点
- 训练思路更直接。
- 本质上仍然是在学“图片区分特征”。

# 四、人脸识别的部署视角

## 1. 训练阶段与推理阶段要分开想

课程里有一个很实用的工程点：**预计算数据库 embedding**。

1. 训练阶段
- 学的是网络参数。
- 目标是所有已有员工学出好的 $f(x)$。

2. 推理阶段
- 数据库中的每张注册照先离线算好 embedding。
- 新图片到来时，只需算一次 $f(x_{\text{new}})$。
- 再与库中 embedding 比较距离或相似度。

3. 这样做的价值
- 不用反复跑整个人脸库的原图。
- 大幅减少在线计算量。

## 2. 为什么商业系统常依赖预训练模型

人脸识别是典型的数据规模驱动任务。

1. 大规模系统往往需要百万级、千万级甚至更大的人脸数据。
2. 这类数据难获取、难清洗、难标注。
3. 所以工程上常直接下载成熟的预训练模型，而不是从零训练。

## 3. 这一段的人脸识别主线总结

到这里应当形成一个完整闭环：

1. one-shot 迫使我们放弃简单 softmax。
2. Siamese 负责把人脸映射到 embedding 空间。
3. Triplet Loss 或二分类方法负责学习“同人近、异人远”。
4. 推理时依赖数据库 embedding 预计算完成快速匹配。

# 五、神经风格迁移的总目标

## 1. 内容图、风格图、生成图分别是什么

NST 先把三张图的角色分清：

| 符号  | 名称                    | 作用                |
| --- | --------------------- | ----------------- |
| $C$ | 内容图像（Content image）   | 提供“画面里是什么”        |
| $S$ | 风格图像（Style image）     | 提供颜色、纹理、笔触、局部统计模式 |
| $G$ | 生成图像（Generated image） | 优化出的最终图像          |

1. 内容不是像素复制。
2. 风格不是物体类别。
3. 最终目标是让 $G$ 同时像 $C$ 的内容、像 $S$ 的风格。

## 2. 总代价函数如何写

NST 的核心就是定义关于 $G$ 的目标函数，然后直接优化像素。

$$
J(G)=\alpha J_{\text{content}}(C,G)+\beta J_{\text{style}}(S,G)
$$

各项作用如下：

| 项                         | 含义   | 作用                    |
| ------------------------- | ---- | --------------------- |
| $J_{\text{content}}(C,G)$ | 内容代价 | 让 $G$ 保留 $C$ 的主体结构    |
| $J_{\text{style}}(S,G)$   | 风格代价 | 让 $G$ 逼近 $S$ 的纹理与色彩统计 |
| $\alpha$                  | 内容权重 | 越大越保内容                |
| $\beta$                   | 风格权重 | 越大越保风格                |

## 3. 优化的对象不是参数，而是图像 $G$

这一点和普通神经网络训练完全不同，是 NST 最容易混淆的地方。

1. 固定一个预训练 CNN，如 **VGG**。
2. 随机初始化图像 $G$。
3. 对 $G$ 的像素做梯度下降：
$$
G:=G-\frac{\partial J(G)}{\partial G}
$$

4. 也就是说：
- 网络参数不更新；
- 真正更新的是生成图本身。

# 六、内容建模：Content Cost

## 1. 为什么内容要在中间层比较

内容是否保住，不应该简单用像素差判断，而应该用某层激活的相似性判断。

1. 若层太浅
- 会过度强调像素级相似。
- 生成图容易被逼成“几乎复制原图”。

2. 若层太深
- 只保留粗糙语义，如“这里有狗、有桥”。
- 会丢掉太多具体结构。

3. 所以课程中的经验是
- 通常选 **中间层** 去表示内容。

## 2. 内容代价函数如何写

设：
- $a^{[l](C)}$：内容图在第 $l$ 层的激活
- $a^{[l](G)}$：生成图在第 $l$ 层的激活

则内容代价可写为：
$$
J_{\text{content}}(C,G)=\frac{1}{2}\left\|a^{[l](C)}-a^{[l](G)}\right\|^2
$$

1. 直觉
- 若两张图在某层激活相近，就说明它们在该层语义上相近。

2. 这个式子在惩罚什么
- 惩罚 $G$ 与 $C$ 在该层 feature representation 的偏离。

3. 工程理解
- 内容损失负责“主体别跑偏”。

## 3. 内容损失真正保留的是什么

这一节需要把“内容”理解得更准确。

1. 保留的是中高层结构信息。
2. 不是逐像素复制。
3. 所以即使颜色、纹理明显变了，只要主体布局和语义结构还在，内容损失仍可较小。

# 七、风格建模：Gram Matrix 与 Style Cost

## 1. 为什么 CNN 特征可视化能引出风格建模

课程先讲 feature visualization，不是旁枝，而是为了说明各层在看什么。

| 层次  | 常见学习内容          | 对 NST 的启发 |
| --- | --------------- | --------- |
| 浅层  | 边缘、颜色块、简单纹理     | 更接近局部风格   |
| 中层  | 组合纹理、局部 pattern | 开始形成风格统计  |
| 深层  | 物体部件、复杂语义       | 更接近内容表达   |

1. 这说明：
- **内容**更像高层语义结构。
- **风格**更像多通道局部特征的统计关系。

2. 所以风格不能只看“这层有没有被激活”。
- 更要看“不同通道是否经常一起激活”。

## 2. Gram Matrix 为什么能表示风格

设第 $l$ 层激活为：
$$
a_{i,j,k}^{[l]}
$$

其中：

- $i$：高度索引
- $j$：宽度索引
- $k$：通道索引

风格图像 $S$ 的 Gram matrix 定义为：
$$
G_{kk'}^{[l](S)}=\sum_{i=1}^{n_H^{[l]}}\sum_{j=1}^{n_W^{[l]}} a_{i,j,k}^{[l](S)}a_{i,j,k'}^{[l](S)}
$$

生成图像 $G$ 的 Gram matrix 同理：
$$
G_{kk'}^{[l](G)}=\sum_{i=1}^{n_H^{[l]}}\sum_{j=1}^{n_W^{[l]}} a_{i,j,k}^{[l](G)}a_{i,j,k'}^{[l](G)}
$$

1. **$G_{kk'}$ 在测什么**
- 测通道 $k$ 与通道 $k'$ 在所有位置上的共同激活程度。

2. **为什么这能表示风格**
- 如果某种纹理一出现，某种颜色区域也常同时出现，那么相关性会高。
- 这反映的是“局部模式共现统计”，而不是具体位置。

3. **一句话直觉**
- Gram matrix 保留的是“这张图的纹理-颜色-局部模式如何共现”。

## 3. 单层风格代价函数怎么理解

风格损失本质上是在比较两张图的 Gram matrix。

$$
J_{\text{style}}^{[l]}(S,G)\propto \left\|G^{[l](S)}-G^{[l](G)}\right\|_F^2
$$

1. 这里的 $\|\cdot\|_F$ 是 **Frobenius norm**。
2. 本质就是矩阵对应元素差值平方和。
3. 若 Gram matrix 越接近，说明两张图的风格统计越接近。

## 4. 为什么常常要多层一起算风格

单层风格损失通常不够稳定，多层组合更自然。

1. 浅层负责边缘、颜色、简单纹理。
2. 更深一些的层负责复杂纹理组合。
3. 因此常写成：
$$
J_{\text{style}}(S,G)=\sum_l \lambda^{[l]}J_{\text{style}}^{[l]}(S,G)
$$

4. 这里的 $\lambda^{[l]}$
- 是各层风格损失的权重。
- 用来平衡低级特征与高级特征的贡献。

# 八、1D / 2D / 3D 卷积的统一视角

## 1. 维度变了，卷积思想没变

这节最重要的不是记尺寸，而是记统一模式。

| 数据类型 | 输入示例 | Filter 示例 | 输出示例 | 典型场景 |
| --- | --- | --- | --- | --- |
| 1D | $14$ 或 $14\times c$ | $5$ 或 $5\times c$ | $10$ 或 $10\times n_f$ | EKG、时间序列、音频 |
| 2D | $14\times14\times3$ | $5\times5\times3$ | $10\times10\times16$ | 图像 |
| 3D | $14\times14\times14\times1$ | $5\times5\times5\times1$ | $10\times10\times10\times16$ | CT、视频块 |

统一规律：

1. filter 总是在局部邻域上滑动。
2. filter 通道数必须与输入通道数匹配。
3. 多个 filter 会产生多个输出通道。

## 2. 1D 卷积适合什么

1D 卷积处理的是序列局部模式。

1. 典型例子：**EKG / ECG**
- 输入是随时间变化的电压序列。
- 每个心跳对应一个局部波形结构。

2. 1D 卷积在学什么
- 在时间轴上反复扫描同一种局部模式 detector。
- 检查某种心跳形状是否在不同时间出现。

3. 与 2D 的共同点
- 仍然是参数共享。
- 只是滑动方向从“平面”变成“时间轴”。

## 3. 3D 卷积适合什么

3D 卷积适合体数据或时空数据。

1. 典型例子：**CT 扫描**
- 数据不是平面图，而是体素块。
- 每个小立方邻域都可能包含空间结构。

2. 另一个例子：视频
- 可把连续帧堆成一个时空块。
- 3D 卷积可以学习动作和运动模式。

3. 维度示例
- 输入若为 $14\times14\times14$，
- 用 $5\times5\times5$ filter，
- 可得到 $10\times10\times10$ 输出；
- 若有 16 个 filter，则输出再带 16 个通道。

## 4. 这节的真正结论

1. 2D CNN 只是卷积思想最常见的落地形式。
2. 卷积本质上是一种“局部结构检测器”。
3. 只要数据有局部相关结构，1D / 2D / 3D 都能套同一思路。

# 九、本周知识闭环

## 1. 人脸识别这条线要记住什么

1. 真正要学的是 embedding，不是封闭类集 softmax。
2. Siamese network 负责构造共享表示空间。
3. Triplet Loss 强制形成“同人近、异人远”的几何结构。
4. 二分类配对训练是另一种可行方案。
5. 工程上常依赖预训练模型和 embedding 预计算。

## 2. NST 这条线要记住什么

1. 内容和风格必须拆开定义。
2. 内容用某层激活相似性表达。
3. 风格用通道相关性，也就是 Gram matrix 表达。
4. 优化对象不是网络参数，而是生成图像像素。

## 3. 卷积推广这条线要记住什么

1. 卷积不是图像专属。
2. 1D 适合序列局部模式。
3. 3D 适合体数据和时空数据。
4. 维度变了，局部连接和参数共享没变。
