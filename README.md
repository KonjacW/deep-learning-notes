# 吴恩达深度学习笔记

这是我学习吴恩达《深度学习专项课程》（Deep Learning Specialization）时整理的中文复习笔记。

笔记由 AI 协助生成初稿，再经人工修改、压缩和补充。内容尽量保留课程的主线、公式含义和常见判断方法，适合已经完整学过一遍课程后回顾、查漏补缺和强化记忆。

## 内容特点

- 以概念之间的联系和训练决策为主，不重复铺开基础推导。
- 将容易混淆的公式、维度、超参数和模型选择放在同一条知识主线上。
- 覆盖从前馈网络、训练优化到 CNN、目标检测和 NLP 词嵌入的核心内容。
- 使用中文编写，文件按课程主题分组，便于按模块复习。

## 目录

| 模块 | 主要内容 |
| --- | --- |
| `1.神经网络基础` | 逻辑回归、浅层网络与深层网络结构 |
| `2.神经网络优化` | 数据划分、正则化、训练诊断、优化算法与训练技巧 |

| `5.循环神经网络` | CNN 基础回顾与 NLP 词嵌入 |

## 使用建议

建议先完成一轮课程学习，再按自己的薄弱环节阅读对应目录。复习时可以结合课程视频、作业和代码实践使用；这里的笔记更适合快速建立知识框架，而不是替代原课程材料。
